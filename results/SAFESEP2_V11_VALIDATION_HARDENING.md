# SAFESEP-II V11 — validation hardening

This validation stage tests two potential failure modes of dynamic behavioral deduplication.

## Branch-created equivalence

Two probes can be behaviorally different at a parent state and become equivalent after an observation removes worlds. Behavioral types are therefore recomputed dynamically on each child branch.

## Grants and revocations together

The strengthened exhaustive battery combines binary observation behavior, requirements, grants, and revocations, with multiple decision maps and an additional probe. It contains 5,184 exact-vs-reduced comparisons.

These cases are part of the computational validation reported in SAFESEP-II V1. Passing computational batteries supports the implementation but does not replace the mathematical proof.
